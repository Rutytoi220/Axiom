# AXIOM Coding Rules

## Mission

Build AXIOM into a local-first AI operating system.

## Priorities

1. Reliability
2. Maintainability
3. Modularity
4. Testability
5. Performance

## Never

- invent APIs
- invent tools
- invent requirements
- rewrite working systems

## Always

- inspect first
- understand architecture
- search before editing
- keep backwards compatibility

## Current roadmap

- Tool Registry
- Skills
- Desktop Automation
- Screen Capture
- OCR
- Vision
- Window Manager
- Mouse Control
- Keyboard Control
- Voice
- Planner
- Memory
- Plugin System
